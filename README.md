# 🏢 Building Destruction 3D 💥

현대 건물을 파괴하며 스트레스를 해소하는 3D 물리 기반 게임!

## 🎮 게임 소개

Building Destruction 3D는 최신 웹 기술을 활용한 고품질 3D 건물 파괴 시뮬레이션 게임입니다.
총과 대포를 사용하여 10단계의 점점 더 강력한 건물들을 파괴하며 스트레스를 해소하세요!

## ✨ 주요 기능

### 🎨 고급 그래픽
- **Three.js** 기반 실시간 3D 렌더링
- 동적 그림자 및 조명 시스템
- 부드러운 안티앨리어싱
- 실시간 파티클 효과

### 🎵 최신 음향 기술
- **Web Audio API**를 활용한 고품질 사운드 시스템
- 실시간 음향 합성 (Oscillator, Filter, Gain Control)
- 무기별 차별화된 발사음
  - 총: 날카로운 연사음
  - 대포: 중후한 폭발음
- 폭발, 충격, 파편 등 다양한 효과음
- 3D 공간감 있는 오디오 믹싱

### 🔧 물리 엔진
- **Cannon.js** 기반 실시간 물리 시뮬레이션
- 사실적인 중력 및 충돌 처리
- 건물 블록간 상호작용
- 폭발 충격파 시뮬레이션

### 🎯 게임플레이
- **10단계 레벨 시스템**
  1. 작은 사무실 (3층)
  2. 일반 빌딩 (5층)
  3. 중형 건물 (7층)
  4. 대형 오피스 (9층)
  5. 현대식 타워 (11층)
  6. 마천루 초입 (13층)
  7. 고층 빌딩 (15층)
  8. 초고층 빌딩 (18층)
  9. 메가 타워 (21층)
  10. 궁극의 요새 (25층)

- **2가지 무기 시스템**
  - 총: 빠른 연사, 보통 위력, 정밀 사격
  - 대포: 느린 연사, 강력한 위력, 범위 폭발

- **파괴 시스템**
  - 블록별 내구도 시스템
  - 누적 데미지 계산
  - 90% 파괴 시 다음 레벨 진행

## 🕹️ 조작법

| 입력 | 동작 |
|------|------|
| **마우스 이동** | 카메라 회전 |
| **마우스 클릭** | 발사 |
| **마우스 휠** | 카메라 줌 인/아웃 |
| **1 키** | 총 선택 |
| **2 키** | 대포 선택 |
| **R 키** | 현재 레벨 재시작 |

## 🛠️ 기술 스택

- **Three.js (r128)**: 3D 렌더링 엔진
- **Cannon.js (0.6.2)**: 물리 엔진
- **Web Audio API**: 실시간 오디오 합성 및 처리
- **Vanilla JavaScript**: 프레임워크 없이 순수 JS로 구현
- **HTML5 Canvas**: 렌더링 출력

## 🎨 그래픽 특징

- **동적 조명**: Ambient Light, Directional Light, Point Light 조합
- **그림자 매핑**: PCF Soft Shadow Map (2048x2048 해상도)
- **재질 시스템**: PBR(Physically Based Rendering) 기반 재질
- **파티클 시스템**:
  - 충격 파티클 (블록 파편)
  - 폭발 파티클 (화염 효과)
  - 파편 파티클 (건물 잔해)

## 🔊 음향 시스템 세부사항

### 오디오 아키텍처
```
AudioContext → OscillatorNode → GainNode → MasterGain → Destination
                              ↓
                         BiquadFilter (선택적)
```

### 사운드 이펙트
1. **폭발음**: 저주파 베이스 + 중음역 폭발 + 고주파 잡음
2. **총 발사음**: 고주파 클릭 + 중음역 임팩트
3. **대포 발사음**: 저주파 붐 + 중음역 폭발음
4. **충격음**: 속도 기반 동적 볼륨
5. **파편음**: 랜덤 주파수 잔해음

## 📊 성능 최적화
